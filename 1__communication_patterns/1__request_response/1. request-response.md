<!-- Request-Response Flow -->

CLIENT ---> REQUEST ---> SERVER
CLIENT <--- RESPONSE <--- SERVER

t0 --> time when client send a request
t2 --> time when server received the request
t30 --> time when server sends the response
t32 --> time when client received the response
t30 - t2 --> request processing time taken by the server

- Client sends a request
- Server parses the request
- Server processes the request
- Server sends a response
- Client parses the response
- Client processes the response

<!-- Where it is used ? -->

- Web, HTTP, DNS, SSH
- RPC
- SQL and Database protocols
- APIs (REST/SOAP/GraphQL)
- Implemented in variations
